# Scenario B (East-West) — AFTER — user-service -> admin-service (DENY-case, lateral movement)

Timestamp (UTC): 2026-08-17T16:20:59Z

Context: giống scenario-b-user-to-order-allow.txt — Istio đã cài,
mTLS STRICT + 3 AuthorizationPolicy đã áp cho namespace crm. Cùng phương
pháp đo với GĐ3: POST tới endpoint giả lập "user-service bị compromise"
trên chính user-service; user-service tự gọi HTTP nội bộ sang
admin-service (ngoài phạm vi nghiệp vụ của nó — mô phỏng lateral
movement từ Vector 2, THREAT_MODEL.md), forward nguyên status/body nhận
được về response này.
